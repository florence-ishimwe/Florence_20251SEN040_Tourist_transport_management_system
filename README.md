## Problem Statement
Many tourism and transport companies face challenges managing customer bookings, vehicle availability, driver assignments, payments, and trip schedules using manual methods. These challenges can lead to booking conflicts, poor record management, and difficulties tracking company operations.

## Objectives
1. To develop a database system for managing customer information and trip bookings.
2. To manage drivers, vehicles, and destinations.
3. To track booking payments.
4. To improve the organization and retrieval of transport records.
5. To use PL/SQL to automate and validate database operations.

## Data Source
The project uses the NYC Taxi and Limousine Commission (TLC) Trip Record Data, specifically the January 2023 Yellow Taxi dataset, as a reference dataset for studying trip-related information and conducting preliminary data analysis.

## Innovation
The system integrates customer bookings, driver and vehicle assignments, destination information, and payment records in one database. PL/SQL features will help automate operations and enforce business rules.
