# Tourist Transport and Trip Management System

## 1. Project Overview
The Tourist Transport and Trip Management System is designed to help transport companies manage tourist transportation services efficiently.

The system will manage drivers, vehicles, customer bookings, trip schedules and vehicle tracking.

## 2. Problem Statement
Managing tourist transportation manually can lead to scheduling conflicts, poor vehicle coordination and difficulties tracking drivers and vehicles during trips.

## 3. Proposed Solution
The proposed system will provide a centralized platform for managing drivers and vehicles, handling customer bookings, scheduling trips and monitoring vehicle locations.

## 4. Main Objectives
- Manage driver information.
- Register and manage vehicles.
- Manage customer bookings.
- Assign drivers and vehicles to trips.
- Organize trip schedules.
- Monitor vehicle locations

## 5. Planned Innovation
Automation for driver and vehicle assignment.

## 6. Technologies
- Database: Oracle Database
- Database language: SQL and PL/SQL
- Version control: GitHub

## 7. Project Status
Under development.
